Saya adalah profesor pembantu kejuruteraan komputer di Universiti Santa Maria, Texas, dan pelawat cendekiawan di Universiti Vanderbilt.
Penyelidikan saya fokus kepada penjaminan keselamatan sistem siber-fizikal.
Secara khusus, saya fokus kepada interaksi antara kekangan masa, sumber dan fungsi, serta impak mereka terhadap prestasi sistem.
Domain aplikasi utama saya adalah sistem pengangkutan dengan fokus khusus penyelidikan terhadap kenderaan pintar, pengurusan sistem pengangkutan, dan kecekapan tenaga.
